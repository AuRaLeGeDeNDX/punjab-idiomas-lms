## Creating Assignments

### Basic Assignment Creation

1. Navigate to the desired subpage
2. Click **"Create Assignment"**
3. Fill in the required fields:
   - **Title**: Clear, descriptive name
   - **Description**: Brief overview (shown in lists)
   - **Instructions**: Detailed requirements
   - **Type**: Homework, Project, Quiz, Exam, or Essay
   - **Submission Type**: Text, File, or Both
   - **Max Score**: Total points possible
   - **Due Date**: When the assignment is due

4. Click **"Create Assignment"**

### Assignment Types

**Homework**: Regular practice assignments
- Best for: Daily/weekly practice
- Typical duration: 1-3 days
- Submission type: Usually file or both

**Project**: Larger, comprehensive assignments
- Best for: End-of-unit assessments
- Typical duration: 1-4 weeks
- Submission type: Usually both (text + files)

**Quiz**: Short assessments
- Best for: Quick knowledge checks
- Typical duration: Same day
- Submission type: Usually text

**Exam**: Major assessments
- Best for: Midterms, finals
- Typical duration: 1-2 hours
- Submission type: Both

**Essay**: Written assignments
- Best for: Critical thinking, analysis
- Typical duration: 1-2 weeks
- Submission type: File or both

### Publishing Options

**Publish Immediately**:
- Check "Publish immediately" box
- Assignment becomes visible to students right away
- Notifications sent to all enrolled students

**Save as Draft**:
- Leave "Publish immediately" unchecked
- Assignment saved but not visible to students
- You can edit and publish later

**Schedule Publication**:
- Enter date and time in "Schedule Publication" field
- Assignment auto-publishes at scheduled time
- Perfect for preparing assignments in advance
- See [Scheduling Assignments](#scheduling-assignments) for details

### Late Submissions

**Allow Late Submissions**:
- Check "Allow late submission" box
- Students can submit after due date
- Submissions marked as "Late"
- You decide if/how to penalize late work

**Don't Allow Late Submissions**:
- Uncheck the box
- Students cannot submit after due date
- Assignment marked as "Missed" if not submitted

## Grading

### Quick Grading

1. Go to submission list
2. Click **"Grade"** next to a submission
3. Enter score and feedback
4. Click **"Save Grade"**

### Enhanced Grading Interface

For detailed grading:

1. Click **"Grade"** on a submission
2. You'll see a split-screen layout:
   - **Left**: Submission content and files
   - **Right**: Grading form

**Features**:
- **File Preview**: View PDFs, images, and text files inline
- **Rich Text Feedback**: Format your feedback with bold, italic, lists, links
- **Quick Comments**: Use pre-written comment templates
- **Rubric Grading**: Score by criteria (if rubric exists)
- **Auto-Save**: Your work saves every 30 seconds
- **Keyboard Shortcuts**:
  - `Ctrl+S`: Save grade
  - `Ctrl+→`: Next submission
  - `Ctrl+←`: Previous submission

### Using Rubrics

If the assignment has a rubric:

1. The rubric appears in the grading interface
2. Score each criterion individually
3. Total score calculates automatically
4. Students see criterion scores when grade is published

**Example**:
```
Content Quality (40 points): 35
Organization (30 points): 28
Grammar (30 points): 27
Total: 90/100
```

### Draft vs. Published Grades

**Draft Grades**:
- Saved but not visible to students
- You can edit anytime
- Useful for grading in multiple sessions

**Published Grades**:
- Visible to students
- Notification sent to student
- Can be locked to prevent changes

### Publishing Grades

**Individual Grade**:
1. Grade the submission
2. Check "Publish immediately"
3. Click "Save Grade"

**Bulk Publish**:
1. Grade multiple submissions
2. Go to assignment page
3. Click "Publish All Grades"
4. Confirm action

### Locking Grades

To prevent accidental changes:

1. View the grade
2. Click **"Lock Grade"**
3. Grade cannot be edited (except by admin override)

**When to Lock**:
- After final grade submission deadline
- When grades are official/reported
- To prevent accidental changes

### Editing Grades

**Unlocked Grades**:
- Click "Edit Grade"
- Make changes
- Save

**Locked Grades**:
- Teachers cannot edit
- Contact admin for override
- Admin must provide reason for override

## Bulk Operations

Save time with bulk operations for multiple submissions.

### Bulk Download

Download all files from multiple submissions:

1. Go to submissions list
2. Check boxes next to submissions
3. Click **"Download All"**
4. ZIP file downloads with all files

**File Organization in ZIP**:
```
submissions_20260202.zip
├── student1_name/
│   ├── essay.pdf
│   └── sources.docx
├── student2_name/
│   └── project.pdf
└── student3_name/
    └── homework.txt
```

### Bulk Reminders

Send reminders to students who haven't submitted:

1. Go to assignment page
2. Click **"Send Reminders"**
3. System automatically identifies non-submitters
4. Confirm sending
5. Notifications sent via email and in-app

**Reminder Message Includes**:
- Assignment title
- Due date
- Link to assignment
- Encouragement to submit

### Bulk Grading

Apply the same grade to multiple submissions:

1. Select submissions to grade
2. Click **"Bulk Grade"**
3. Enter score and feedback
4. Confirm action
5. All selected submissions receive the same grade

**When to Use**:
- Participation assignments (everyone gets same credit)
- Completion-based assignments
- Extra credit opportunities

**Warning**: Use carefully! Each student receives identical grade and feedback.

### Bulk Publish Grades

Publish all graded submissions at once:

1. Go to assignment page
2. Click **"Publish All Grades"**
3. Confirm action
4. All unpublished grades become visible
5. Notifications sent to all students

**Best Practice**: Review all grades before bulk publishing.

## Templates & Rubrics

### Assignment Templates

Save time by reusing assignment structures.

#### Creating a Template

**From Scratch**:
1. Go to **Templates** page
2. Click **"Create Template"**
3. Fill in template details
4. Click **"Save Template"**

**From Existing Assignment**:
1. Go to assignment page
2. Click **"Save as Template"**
3. Template created with all assignment details

#### Using a Template

1. Click **"Create Assignment"**
2. Click **"Use Template"**
3. Select template from list
4. Form pre-fills with template data
5. Customize as needed
6. Create assignment

#### Public vs. Private Templates

**Private Templates**:
- Only you can see and use
- Default setting

**Public Templates**:
- All teachers can use
- Great for department-wide standards
- Check "Make Public" when creating

#### Managing Templates

- **Edit**: Update template details
- **Delete**: Remove template
- **Duplicate**: Create copy to modify
- **View Usage**: See which assignments used this template

### Rubrics

Create consistent grading criteria.

#### Creating a Rubric

1. Create or edit an assignment
2. Scroll to **"Rubric"** section
3. Click **"Create Rubric"**
4. Enter rubric title and description
5. Add criteria:
   - **Criterion Name**: e.g., "Content Quality"
   - **Description**: What you're looking for
   - **Max Points**: Points for this criterion
6. Add more criteria as needed
7. Ensure total points = assignment max score
8. Save assignment

**Example Rubric**:
```
Essay Rubric (100 points total)

1. Content Quality (40 points)
   - Depth of analysis
   - Accuracy of information
   - Use of evidence

2. Organization (30 points)
   - Clear thesis statement
   - Logical flow
   - Effective transitions

3. Grammar & Mechanics (30 points)
   - Spelling and grammar
   - Proper citations
   - Formatting
```

#### Grading with Rubrics

1. Open submission for grading
2. Rubric appears automatically
3. Score each criterion
4. Total calculates automatically
5. Add overall feedback
6. Save grade

**Benefits**:
- Consistent grading across students
- Clear expectations for students
- Faster grading process
- Detailed feedback by category

#### Editing Rubrics

**Before Grading Starts**:
- Edit freely
- No impact on existing grades

**After Grading Starts**:
- Be cautious with changes
- May affect grade calculations
- Consider creating new rubric instead

## Advanced Features

### Scheduling Assignments

Prepare assignments in advance and auto-publish later.

#### How to Schedule

1. Create or edit assignment
2. Scroll to **"Publishing"** section
3. Enter date and time in **"Schedule Publication"** field
4. Leave "Publish immediately" unchecked
5. Save assignment

**What Happens**:
- Assignment stays in draft status
- Shows "Scheduled" badge with date/time
- Auto-publishes at scheduled time
- Notifications sent automatically

#### Viewing Scheduled Assignments

- Look for blue "Scheduled" badge
- Date/time shown below badge
- Click to edit or cancel schedule

#### Canceling a Schedule

1. Find scheduled assignment
2. Click cancel button (⊗ icon)
3. Confirm cancellation
4. Assignment returns to draft status

#### Best Practices

- Schedule assignments for start of class
- Prepare week's assignments on Sunday
- Schedule during off-hours (early morning)
- Double-check date/time before saving

### Submission Versioning

Track student revisions automatically.

#### How It Works

- Student submits assignment
- Student edits and resubmits
- System saves both versions
- You can view all versions

#### Viewing Version History

1. Open submission
2. Click **"View History"** (if multiple versions exist)
3. See all versions with timestamps
4. Click version to view content

#### Comparing Versions

- View side-by-side comparison
- See what changed between versions
- Identify improvements or issues

**Use Cases**:
- Verify student did their own work
- Track improvement over time
- Identify when issues were introduced
- Provide feedback on revision process

### Grade Overrides (Admin Only)

If you're an administrator, you can override locked grades.

#### When to Override

- Grading error discovered after locking
- Student appeal approved
- Special circumstances
- Administrative correction

#### How to Override

1. View locked grade
2. Click **"Override Grade"**
3. Enter new score
4. **Required**: Provide detailed reason (min 10 characters)
5. Confirm override

**What Happens**:
- Grade updated to new score
- Original grader notified
- Override logged with:
  - Your name
  - Original score
  - New score
  - Reason
  - Timestamp

#### Viewing Override History

1. View grade
2. Click **"View Override History"**
3. See all overrides with details

## Tips & Best Practices

### Assignment Creation

✅ **DO**:
- Write clear, specific instructions
- Include examples when helpful
- Set realistic due dates
- Specify file formats accepted
- Provide grading rubric upfront

❌ **DON'T**:
- Use vague language
- Set unrealistic deadlines
- Change requirements after publishing
- Forget to specify submission type

### Grading

✅ **DO**:
- Grade promptly (within 1 week)
- Provide constructive feedback
- Use rubrics for consistency
- Save drafts if interrupted
- Publish all grades at once

❌ **DON'T**:
- Grade when tired or rushed
- Use only negative feedback
- Change rubric after grading starts
- Forget to publish grades

### Communication

✅ **DO**:
- Send reminders for upcoming due dates
- Acknowledge receipt of submissions
- Explain grading delays if needed
- Respond to student questions promptly

❌ **DON'T**:
- Assume students saw the assignment
- Leave students wondering about grades
- Ignore submission issues

### Organization

✅ **DO**:
- Use consistent naming conventions
- Create templates for recurring assignments
- Schedule assignments in advance
- Export grades regularly for backup

❌ **DON'T**:
- Create assignments at the last minute
- Forget to back up important data
- Mix up assignment types

### Analytics

✅ **DO**:
- Check dashboard weekly
- Identify at-risk students early
- Adjust teaching based on data
- Celebrate class successes

❌ **DON'T**:
- Ignore warning signs
- Wait until end of term
- Rely only on final grades

## Troubleshooting

### Common Issues

#### "Assignment won't publish"

**Possible Causes**:
- Missing required fields
- Invalid due date (in the past)
- No students enrolled in course

**Solutions**:
1. Check all required fields are filled
2. Verify due date is in the future
3. Confirm students are enrolled
4. Check browser console for errors

#### "Can't see student submissions"

**Possible Causes**:
- Assignment still in draft
- No submissions yet
- Filter hiding submissions

**Solutions**:
1. Verify assignment is published
2. Check submission deadline hasn't passed
3. Clear all filters
4. Refresh the page

#### "Grade won't save"

**Possible Causes**:
- Score exceeds max score
- Grade is locked
- Network connection issue

**Solutions**:
1. Verify score ≤ max score
2. Check if grade is locked
3. Check internet connection
4. Try saving again

#### "Bulk download fails"

**Possible Causes**:
- Too many files selected
- Large file sizes
- Server timeout

**Solutions**:
1. Select fewer submissions
2. Download in batches
3. Contact IT if persistent

#### "Rubric total doesn't match"

**Possible Causes**:
- Criterion points don't sum to max score
- Math error in criterion points

**Solutions**:
1. Add up all criterion max points
2. Adjust criterion points to match assignment max score
3. Save rubric again

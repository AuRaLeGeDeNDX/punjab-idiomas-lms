# File Upload Quick Reference

## 🚀 Quick Start

1. **Choose content type** → **Select file** → **Upload**
2. **Drag & drop** files directly onto upload area
3. **Watch progress bar** for large files
4. **Retry** failed uploads with one click

## 📁 Supported File Types

| Type | Formats | Max Size | Best For |
|------|---------|----------|----------|
| **Images** | JPG, PNG, GIF, WebP | 10 MB | Photos, graphics, diagrams |
| **Documents** | PDF | 50 MB | Course materials, handouts |
| **Audio** | MP3, WAV, OGG, M4A | 100 MB | Lectures, podcasts |
| **Video** | MP4, WebM, OGG, MOV | 500 MB | Tutorials, demonstrations |

## ⚡ Quick Fixes

### File Too Large?
- **Images**: Compress with TinyPNG or reduce dimensions
- **PDFs**: Use PDF compression tools
- **Audio**: Convert to MP3 with lower bitrate (128-192 kbps)
- **Video**: Reduce resolution or use better encoding

### Wrong File Type?
- Check supported formats above
- Convert using online tools or software
- Ensure extension matches actual file type

### Upload Failed?
1. **Check internet connection**
2. **Click "Retry" button**
3. **Try different browser**
4. **Clear browser cache**

### File Corrupted Error?
1. **Open file on your computer** to verify
2. **Re-save from original application**
3. **Check file extension matches content**

## 💡 Pro Tips

- **Use descriptive filenames** (no spaces or special characters)
- **Upload during off-peak hours** for large files
- **Use wired internet** for better stability
- **Keep browser open** until upload completes
- **Save correlation IDs** from error messages for support

3. **Try troubleshooting steps** in full user guide
